## Verificar la autoría

El sistema lleva un sello de autoría comprobable:

```bash
python -m contaflow.firma
```

o, con la aplicación en marcha, abriendo `http://127.0.0.1:8777/firma`.

El sello incluye una huella SHA-256 que permite detectar si alguien alteró su
contenido.
